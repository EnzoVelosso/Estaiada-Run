# Estaiada-Run
Sistema em Python para automação de inscrições, validação de regras de negócio, cálculo de pace e gestão completa dos resultados e premiações da Corrida Noturna da Ponte Estaiada (Assessoria Passo Certo).
para a disciplina de programação I (UNIFSA)

# Funcionalidades:
-Etapa I(Inscrição e resultado de um corredor): Focada no atendimento individualizado e na estruturação lógica inicial.
-Etapa II(A corrida inteira): Focada na gestão coletiva e persistência de dados em memória durante a execução.

# Decisão da dupla
Para garantir a distribuição equilibrada dos commits e a participação ativa de ambos no versionamento do código, decidimos intercalar trechos do projeto a cada commit, alternando a implementação de funções e melhorias estruturais no repositório.
